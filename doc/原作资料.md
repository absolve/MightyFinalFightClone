# NES《快打旋风》(Mighty Final Fight) 原作资料

> 供复刻设计对照用的一手资料汇总，来源见文末。与既有设计文档冲突之处，以本文为准并已在 [功能设计.md](功能设计.md) / [后续实现计划.md](后续实现计划.md) 修正。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 原名 | マイティ ファイナルファイト / Mighty Final Fight |
| 开发 / 发行 | Capcom（制作人：藤原得郎 Tokuro Fujiwara） |
| 发售 | 日版 1993-06-11；美版 1993-07；欧版 1993-08 |
| 平台 | FC/NES |
| 人数 | **仅单打**（无双人合作） |
| 收录 | 2006 年 GBA 合集《Final Fight One》收录 |

与街机版关系：剧情沿用（营救 Jessica、最终 Boss 是机械改造的 **Cyborg Belger**），角色 Q 版二头身，系统改为**等级制**，不是街机版移植。

## 2. 操作

| 按键 | 作用 |
|---|---|
| 十字键 | 移动 |
| B | 攻击（连打=连续拳） |
| A | 跳跃 |
| START | 开始 / 暂停 |
| SELECT | 无作用 |

投掷：抓住敌人后 ←/→+B 掷出；或连按 B 三拳后 ↓/↑+B 上下掷。

## 3. 核心系统

### 3.1 等级 / 经验（最高 LV6）

- 打倒敌人、或**体力全满时吃到回复道具**，获得 EXP；EXP 满了升级，**体力上限与攻击力提升**。
- 各角色升级所需 EXP（累计值，源自 nesbbs 资料；LV1→3 数值未公开）：

| 等级 | Cody | Guy | Haggar |
|---|---|---|---|
| LV4 | 90 | 74 | 125 |
| LV5 | 147 | 122 | 193 |
| LV6 | 250 | 210 | 370 |

- Guy 升级最快，Haggar 最慢（与"Guy 所需 EXP 最少"的速通资料一致）。
- **Haggar 开局即为 LV3**，Cody/Guy 为 LV1；续关（continue）时换人，新角色以 LV3 出场。

### 3.2 特殊攻击

- **必须 LV4 以上才能使用**（说明书原文："You will not be able to execute your special attacks unless you are at level 4"）。
- 输入是**时机型**而非搓招型（"extremely difficult to perform, so practice your timing"）：**攻击后迅速按前**。

| 角色 | 特殊攻击 | 说明 |
|---|---|---|
| Cody | Tornado Sweep | 把气集中在手上放出，**远程能量攻击**（对应音效 发出光波/集聚光波） |
| Guy | Tornado Kick | 龙卷旋风踢（对应音效 旋风腿） |
| Haggar | Running Clothesline | 冲刺旋风臂，又称 "Scramble Haggar Press" |

### 3.3 其他动作（全员通用）

| 输入 | Cody/Guy | Haggar |
|---|---|---|
| A+B 同时按 | Super Kick | Spinning Clothesline |
| 抓住敌人按 B | Knee Bash（膝撞） | Head Butt（头撞） |
| 空中 ↓+B | Knee Drop / Elbow Drop（下坠攻击） | 同左 |

### 3.4 Guy 隐藏技

1. **武神流穿心腿**：面向右时 A 跳起，立即按住 ←+↑ 并不放连打 B（面向左时方向镜像）。威力随等级提升。
2. **脚刀**：穿心腿后落地前按住 ↓ 蓄力，落地瞬间 ↑+B 追加。

### 3.5 HUD（重要：无分数、无计时器）

- 顶部：PLAYER 血条（红色分段）、ENEMY 血条（Boss 战出现）、RD（回合）、PL×N（剩余命数）。
- 底部：**LEVEL n** 与 **EXP 数值/升级所需**（如 "EXP 000/125"），Boss 击败后显示 "ROUND CLEAR" 替代。
- **原作没有 score 计分，也没有任何倒计时**。本 clone 早期设计文档中的"分数、计时器"系误传，已修正。

### 3.6 初始血量与伤害（数值考据现状）

> 结论先行：**初始体力值与每次攻击伤害的精确数字，公开资料（说明书 / 攻略 / Wiki）均未给出**，需 ROM 实测或解包 RAM 地址后才能确认。目前可确认的事实如下。

- 体力以**红色分段血条**显示（本作 HUD 为 16 格），升级后血条格数增加。
- nesbbs 原文："等级提升后**体力长度和攻击力有所增加**"——升级同时加体力上限与攻击力，但没有公开具体增量。
- Haggar 开局 LV3（§3.1），因此开局体力上限即高于 LV1 的 Cody/Guy；攻击力的等级差体现为"Haggar 力量型、Guy 速攻型"的攻略共识。
- 敌人侧可确认的是**连击数上限**而非伤害数值：说明书原文 "There's a certain amount of hits you can apply to an enemy before you knock them down."——每个敌人有固定的可承受连击数，打满即倒地（详见 §3.7）。
- **对 clone 的影响**：`maxHp` / 攻击力数值暂按自设（见 [后续实现计划.md](后续实现计划.md) 阶段 10 数值差异化），考据数据到手后再对齐；HUD 分段血条已按 16 格实现，格数随等级增长的设计与原作一致。

### 3.7 出拳与连段规则（命中驱动，非固定连段）

原作出拳行为与常见"按几下出第几段"的连段设计**不同**，核心规则：

1. **空挥（没打中）：** 连按 B 只会**反复播放同一个出拳动作**，不换招、不递进。
2. **命中后：** 拳连续命中敌人时进入 **Rapid Hits（连续快拳）**，连段持续推进；连打拳后可接 **Drop Kick（双脚踢）** 收尾（GameFAQs 1998 招式表原文："Keep punching an enemy : Rapid Hits, followed by Drop Kick"）。
3. **敌人倒地：** 每个敌人有可承受连击数上限，打满即倒地（说明书原文见 §3.6）——连段长度受敌人"韧条"限制，而不是角色招式表限制。
4. 即"**是否换段取决于有没有打中**"：打不中永远是同一招，打中才推进连段，连段终点是敌人倒地或追加终结技。

**对 clone 设计的影响**：本项目当前 `attackState` 是 act1→act2→act3 **按时序/输入手动递进**（见 [功能设计.md](功能设计.md) §1），与原作"命中驱动"规则不一致。若要还原手感，应改为：攻击键按下只触发当前段；命中后允许输入下一段（rapid hits）；敌人连击数满强制倒地。建议在阶段 2（战斗系统）实现时按此调整。

## 4. 角色

| 角色 | 初始等级 | 特点（街机系谱） |
|---|---|---|
| Cody | LV1 | 均衡型，速度一般；特殊攻击为唯一远程手段 |
| Guy | LV1 | 速度最快，升级所需 EXP 最少，隐藏技最多 |
| Haggar | LV3 | 力量型，投技（头撞/旋风臂）强，升级最慢 |

## 5. 关卡与 Boss（共 5 个 Round，每关分 Area）

| Round | 名称 | Boss / 备注 |
|---|---|---|
| 1 | Slum | **Damnd**（日版名 Thrasher）；战前有对话选项 |
| 2 | Riverside | Sodom 登场；其后回合出现红黑两兄弟 **Masamune / Murasame** |
| 3 | Old Town（日版写作 "Habor Town"，系原作拼写错误） | **Abigail**；日版战前有问答，答对得续关奖励 |
| 4 | Factory | 含 **Bonus Stage**（奖励关） |
| 5 | Bay Area | 最终 Boss **Cyborg Belger** |

每关内部再分 Area（如 5-2 表示 Round 5 Area 2）；Round 2 Area 2 等有独立地图。第 4 关含奖励关。

## 6. 敌人

街机系谱的 Q 版敌人：Bred、Two P、Axl、J、Dug 等；Boss 见上表。
（速通资料提示 Two P 比 Bred 危险，应优先击杀。）

## 7. 道具

- 回复类食物道具（烤肉、汉堡等），吃后回复体力；**满血吃回复道具可获得 EXP**。
- 强化道具（power-up items）。
- 彩蛋：Round 5 Area 2 路边广告牌上画有一块肉，对着图案打几拳可**补满体力**。
- 原作以徒手肉搏+投掷为主，**没有可拾取武器系统**（街机版的刀/钢管/油桶不属于本作）。

## 8. 版本差异

- 日版标题画面无 "LICENSED BY NINTENDO"，美/欧版有。
- Round 3：日版地图名 "Habor Town"（拼写错误），欧美版改 "Old Town"；日版保留 Abigail 战前问答环节，国际版删除。
- Round 1：与 Damnd 对话，国际版答 "no" 使其退缩掉血；日版措辞不同，答 "yes" 反而受伤。
- GBA 合集版字体整体调整。

## 9. 续关

命数耗尽后 continue；日版 Round 3 问答环节连续答对可获得续关奖励。换人规则见 §3.1（新角色 LV3 出场）。

## 10. 对设计文档的修正清单

| # | 原设计 | 修正 |
|---|---|---|
| 1 | HUD 含"分数、计时器" | 原作只有 LEVEL/EXP；HUD 已改为 LEVEL+EXP 显示，删除计时器与分数 |
| 2 | §1 把"旋风腿、倒勾脚、dragon_fist、光波"列为原作必杀 | 原作特殊攻击仅 3 个：Tornado Sweep / Tornado Kick / Running Clothesline，且 LV4+、时机输入；倒勾脚、dragon_fist 非本作招式（系街霸 Cody 系谱）。搓招系统保留为本 clone 扩展，不再标注为"原作" |
| 3 | §8 道具武器（刀/棍/油桶） | 改为非原作扩展项，延后/可选；道具以回复食物+强化道具为主 |
| 4 | 无等级系统设计 | 本文 §3.1 补 EXP 数据表（LV4-6），阶段 10 角色数值差异化据此设计 |
| 5 | 计划默认双人（P1/P2） | 注明原作仅单打；双人保留为扩展（阶段 10 已列） |
| 6 | 关卡/Boss 无清单 | 本文 §5 给出 Round 1-5 名称与 Boss 顺序 |
| 7 | 连段按输入固定递进（act1→2→3） | 原作为命中驱动：空挥反复同一招、命中才推进 rapid hits、敌人连击数满倒地；见 §3.7 |
